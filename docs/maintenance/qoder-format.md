# Qoder CN format surface

Generated by `qcut format`. Everything this tool assumes about Qoder CN's
own files. Re-verify after a Qoder update; see docs/maintenance/.

## Layout (relative to ~/.qoder-cn)

- transcripts: `projects/**/*.jsonl`
- skill manifests: `skills/**/SKILL.md`
- plugin index: `plugins/installed_plugins_v2.json, plugins/installed_plugins.json`
- MCP servers: `mcp.json`
- settings (BYOK routes): `settings.json`
- line separator: `b'\n'`

## Record types

- claimed: assistant, runtime-config, system, user, workspace-directories
- claimed and dropped: active-leaf, attachment, custom-title, file-history-snapshot, last-prompt, worktree-state
- anything else is counted in `unparsed` as `type:<name>`

## Fields read

- record: customProviderId, cwd, directories, entrypoint, gitBranch, isSidechain, message, modelSource, parentUuid, sessionId, sourceToolAssistantUUID, subtype, timestamp, toolUseResult, type, userType, uuid, version
- message: content, id, model, role, stop_reason, stop_sequence, type, usage
- usage: billable, cache_creation_input_tokens, cache_read_input_tokens, context_usage_ratio, credits, input_tokens, original_credits, output_tokens, request_id
- tool_use: id, input, name, type
- tool_result: content, is_error, tool_use_id, type
- toolUseResult: agentType, commandName, durationMs, exitCode, interrupted, isError, isImage, kind, signal, status, timedOut
- tool arguments: agent_type, skill, subagent_type, toolName
- inventory JSON: baseUrl, installPath, mcpServers, plugins, providers, source, version

## Classification

- skill tool: `Skill` (argument `skill`)
- agent tool: `Agent` (argument `subagent_type`, default `general-purpose`)
- mcp tools: `mcp_call` -> call, `mcp_get` -> get, `mcp_list` -> list
- mcp target: `mcp__<server>__<tool>` in the `toolName` argument
- custom route: `<providerId>/<model>`, prefix `qoder-custom-`
